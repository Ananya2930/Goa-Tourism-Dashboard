# Interactive Tableau Dashboard on Goa Tourism
## Project Objective
To provide a data-driven analysis of Goa’s tourism landscape (2019–2022) using 5,000 tourist records. This interactive dashboard identifies actionable patterns in demographics, spending behavior, and seasonal trends to support informed decision-making for stakeholders.

## Project Insights
- Consistent Satisfaction: Averages a high 4.0/5 across all travel purposes, including Wellness, Adventure, and Business.
- Balanced Demographics: Maintains a steady, near-equal split between domestic and international travelers (2019–2023).
- Regional Strengths: North Goa leads in Water Sports (381) and Historical Sites (367), while South Goa excels in Yoga Retreats (372).
- Steady Demand: Tourist footfall and booking platform usage remained highly stable from 2019 to 2023.

## Conclusion
Goa is a highly lucrative market, yielding an average trip spend of ₹41,273 and a consistent 4.0/5 visitor satisfaction rate. To drive future growth, stakeholders should deploy targeted regional marketing by promoting high-energy activities in North Goa and wellness retreats in South Goa.
